# 학습 일정 (study-plan)

`schedule.html` 하나로 동작하는 학습 일정 체크 페이지. 체크 상태는 브라우저 localStorage에 저장된다.

## 기간과 구성 (2026-09-30 ~ 2027-02-02, 18주)
| 구간 | 내용 |
|---|---|
| 1~7주 (09/30~11/17) | 굿메디슨 프로젝트 학습 중심 + 코테(10/5~) + CS + SQL + 학술제(포스터 10/16, 시연 영상 10/26~30, 본선 11/10) + 정처기 필기 1h(10/6~) |
| 8~12주 (11/18~12/20 근처) | 하루 6시간 제한 해제. 정처기 필기 이론 2회독 + 실기 연계 1h + 코테 월·수·금 1h |
| 12~15주 | 기출 회독 (모의 → 오답 → 약한 단원) |
| 16~17주 | 약점 집중, 암기, 최종 모의 |
| 18주 (1/27~2/2) | 시험 주간. 정처기 필기 **2027-01-30 (예상일)** |

## 현재 상태
- 일정 작성 완료. 시험일은 2027년 1회차를 가정한 추정이며 큐넷 공고 후 `EVENTS`와 18주차 항목을 조정해야 한다.
- 실기 전용 범위(필기에 없는 알고리즘 구현 등)는 필기 합격 발표 후 계획한다.
- 학습 진행도는 브라우저에만 저장되므로 이 저장소에는 없다.

## 수정 방법
- `PLAN` 배열의 `days`에 `P/C/N/S/X/R/E/Q` 헬퍼로 항목을 추가한다 (프로젝트·코테·CS·SQL·학술제·복습·정처기·정처기 실기).
- 항목은 각 날짜 배열의 **끝에** 추가해야 기존 체크 상태(`날짜|순번`)가 어긋나지 않는다.
